# Together we can

Edit app.json words and starter settings. Phone: /<id>/open; wall: /<id>/tv. A site/pages/<id>/index.html replaces only the landing. Records are public; use references, never private contact details. Staff updates require an account grant.

Giving totals are public intentions, not received money. The gift link opens the studio shop. Use `shop init --giving --currency CAD` and connect the organisation’s Stripe account. Monthly renewals are managed in Stripe.

The new subscription Checkout API is documented in `shop/SHOP.md` (“give $20
monthly”). `interval: 'month'` now opens subscription-mode Checkout with a runtime
Stripe connection; lifecycle events and a buyer-owned portal endpoint are available.
This starter's intention scene has not yet been converted to verified giving totals.
Do not present its monthly intentions as collected payments.
