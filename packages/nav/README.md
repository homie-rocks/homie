# @homie-rocks/nav

Tiled navigation meshes from triangles or a heightfield, seeded queries, fixed-step
crowds and flat grid paths. The same modules run in Node, a browser and a Worker.

Part of Homie's open game engine: the packages the Homie games are built on.

## Install

```sh
npm install --save-exact @homie-rocks/nav@0.1.0
```

There is no barrel file: import the module you need.
