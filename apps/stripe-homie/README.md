# Homie

Public Stripe App using `restricted_api_key` authentication, with only a settings
view. No backend, OAuth callback, developer credential or homie.rocks dependency.

`npm ci && npm run build && npm test` checks the local source. Nothing uploads.
See [the owner guide](../../docs/stripe-rak-owner-guide.md) for exact owner-approved
upload and Dashboard External test steps, template provenance, and sandbox gates.
